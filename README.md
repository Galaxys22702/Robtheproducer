# Robtheproducer

Independent Las Vegas sound engineering and music production website.

## Files
- `index.html`: accessible, responsive single-page site.
- `styles.css`: dark plum and pink visual theme; no external font requests.
- `script.js`: progressive mobile navigation, Escape support and current year.

## Preview
Serve the repository using any static web server, or open `index.html` directly.
No packages, API keys or build step are required.

## Publishing
The source is ready for static hosting. For GitHub Pages, select **Settings → Pages → Deploy from a branch → main → /(root)** and save. Hosting activation and the live URL must be verified separately.
